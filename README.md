## Engineering trustworthy software and intelligent systems

I am a **Computer Engineering graduate from Khalifa University** building local AI, full-stack products, humanoid robotics, embedded intelligence, computer vision, networking, and real-time systems.

My favorite engineering problems cross boundaries: retrieved evidence must be traceable, privileged actions must be reviewable, sensors must be trusted, interfaces must respond clearly, and the result must survive measurable testing.

> **My engineering loop:** understand the system → define the trust boundary → build the smallest reliable change → verify it with evidence.

### 🛡️ LocalGuard AI — Evidence before action

A CPU-only document intelligence system for PDF, DOCX, and TXT files. It combines pgvector and PostgreSQL full-text retrieval, resolves citations to immutable source offsets, and keeps every AI-proposed task behind authenticated LangGraph review.

**Verified evidence:** 25/25 pinned-Ollama cases · 1.0000 citation precision · 7/7 approval transitions · 384 Python tests · 45 integration tests · 46 frontend tests · five passing CI jobs

`FastAPI` `Next.js` `PostgreSQL` `pgvector` `LangGraph` `Ollama` `Docker`
